Privacy Policy

Fly Infinity Auto Backup

Effective date: November 12, 2026

Fly Infinity Auto Backup is an owner-operated utility. It is intended to create backups of GitHub repositories and selected Cloudflare resources into the owner's own Google Drive. It is not a public file-hosting or consumer account service.

1. Who operates this utility

Fly Infinity Auto Backup is operated by the owner of the Fly Infinity project. For privacy questions about this utility, contact flyinfinityplatform@gmail.com.

2. Information and resources processed

When the owner configures and enables the backup workflow, the utility may process only the resources selected for backup, such as:

  • Repository source files and Git history available to the configured GitHub workflow.
  • Selected Cloudflare account metadata, Workers and Pages configuration or source files, and database exports, where the configured read permissions allow access.
  • Backup status information, timestamps, filenames, and technical logs needed to run and troubleshoot the scheduled workflow.

The utility does not request Google profile, Gmail, contacts, calendar, or general Google Drive access. Its Google Drive authorization is limited to the drive.file permission, which is intended for files created by this application or files the user explicitly opens or selects for it.

3. How Google Drive is used

Google Drive is used as the owner's backup destination. Backup archives are uploaded to the Google account and Drive folder selected by the owner. The utility does not use the Drive connection to search unrelated personal files or to read the owner's entire Drive.

4. Credentials and security

OAuth credentials, refresh tokens, GitHub secrets, and Cloudflare API tokens are intended to be stored as encrypted repository or organization secrets in GitHub Actions and are not intended to be committed to source code or included in backup archives. Cloudflare access should use a token limited to the read permissions required for the selected resources.

No internet-connected service can guarantee absolute security. The owner is responsible for protecting the Google account, GitHub account, Cloudflare account, recovery methods, and access to the backup destination.

5. Sharing and sale

Backup contents are intended for the owner's own recovery and administration. They are not sold, rented, or shared by the operator for advertising. The utility does not use backup contents to build advertising profiles. Data is processed by the service providers necessary to operate the workflow, including GitHub, Cloudflare, and Google, under their respective terms and privacy policies.

6. Retention and deletion

Backup files remain in the owner's Google Drive until the owner deletes them or configures an automated retention policy. The owner can delete backup files directly in Drive and can revoke the application's Google access through the Google Account security settings. GitHub workflow logs and provider-side operational records may remain subject to the relevant provider's retention practices.

8. Changes to this policy

This policy may be updated if the backup workflow, permissions, or data handling practices change. The effective date at the top of this page will be revised when material changes are made.

9. Contact

For questions about this privacy policy or the backup utility, email flyinfinityplatform@gmail.com.
